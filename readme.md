# HR Toolkit

## ⚙️ Technologies Used

### 💬 Languages
- **HTML5**: Semantic markup structuring the web components.
- **CSS3**: Custom styling, CSS variables for theming, and responsive layouts.
- **JavaScript (ES6+)**: Core application logic, native Web Components, and asynchronous state management.

### 🧩 Libraries & Frameworks
- **Firebase (Firestore)**: Cloud NoSQL database for production data persistence.

### 🛠️ Development Tools
- **Vite**: Next-generation frontend tooling used for lightning-fast HMR and optimised production bundling.
- **Terser**: JavaScript minifier for optimising production builds.
